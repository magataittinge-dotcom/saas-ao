# Expert Scoring & Notation des Offres — Marchés Publics BTP

## Comment les acheteurs notent les offres

### Formules de notation du prix
Les acheteurs utilisent principalement 3 formules :

**1. Inversement proportionnel (la plus courante)**
Note = (Prix le plus bas / Prix du candidat) × Note maximale
Exemple : prix mini = 100k, votre prix = 120k → Note = (100/120) × 20 = 16.67/20

**2. Écart relatif**
Note = Note max × [1 - ((Prix candidat - Prix mini) / Prix mini)]
Avec plancher à 0

**3. Moyenne**
Note = Note max × (Prix moyen / Prix candidat)
Avantage : moins sensible aux offres anormalement basses

### Notation de la valeur technique
Chaque sous-critère est noté sur une échelle (souvent 0-5 ou 0-10) :

| Note | Signification | Ce que l'acheteur voit |
|------|--------------|----------------------|
| 0/5 | Pas de réponse ou hors sujet | Aucun élément sur ce point |
| 1/5 | Très insuffisant, générique | Copier-coller évident, pas adapté |
| 2/5 | Insuffisant, partiel | Quelques éléments mais lacunes importantes |
| 3/5 | Correct, conforme | Répond aux attentes sans plus |
| 4/5 | Bon, bien adapté | Éléments différenciants, bien personnalisé |
| 5/5 | Excellent, valeur ajoutée | Parfaitement adapté, innovations, preuves concrètes |

### Pondération type BTP
- Prix : 30-60% (moyenne 40%)
- Valeur technique : 40-70% (moyenne 50%)
  - Méthodologie : 20-30%
  - Moyens humains : 15-25%
  - Planning : 10-20%
  - Qualité/Sécurité : 10-15%
  - Environnement : 5-15%
- Délai : 0-15%
- RSE / Développement durable : 0-20%

## Stratégies pour maximiser la note technique

### Pour passer de 3/5 à 5/5 sur chaque critère :

**Méthodologie (critère roi)**
- 3/5 : Description correcte des phases de travaux
- 5/5 : Étapes détaillées avec normes DTU citées, schémas, traitement des points singuliers, contraintes spécifiques du chantier, solutions innovantes

**Moyens humains**
- 3/5 : Liste des postes et qualifications
- 5/5 : Noms réels, CV, certifications, organigramme spécifique au chantier, plan de remplacement

**Planning**
- 3/5 : Planning Gantt basique avec les grandes phases
- 5/5 : Planning détaillé avec jalons, interfaces entre lots, période de préparation, contingences, plan de rattrapage

**Qualité/Sécurité**
- 3/5 : PAQ générique + PPSPS standard
- 5/5 : PAQ adapté au chantier, fiches d'autocontrôle spécifiques, analyse des risques du chantier, EPI spécifiques, plan de prévention détaillé

**Environnement**
- 3/5 : SOGED basique, tri des déchets
- 5/5 : SOGED détaillé avec filières, objectifs chiffrés de valorisation, mesures anti-nuisances, bilan carbone, matériaux biosourcés

## Détection d'offre anormalement basse (OAB)
- L'acheteur DOIT détecter les OAB (art. L2152-5 CCP)
- Seuil indicatif : prix < 80% de l'estimation ou < 80% de la moyenne des offres
- Le candidat est invité à justifier son prix
- Si justification insuffisante → rejet de l'offre
- Conseil : ne jamais casser les prix sans justification solide

## Erreurs qui tuent la note
1. Ne pas répondre à un sous-critère mentionné dans le RC
2. Mémoire technique générique (non adapté au DCE)
3. Pas de planning
4. Pas de noms réels dans l'équipe
5. Références sans rapport avec le marché
6. Pas de fiches techniques des matériaux
7. Orthographe/grammaire négligée
8. Trop court (< 10 pages) ou trop long (> 30 pages)
9. Pas de visuels (photos, schémas, tableaux)
10. Pas de quantification (chiffres, dates, montants)
