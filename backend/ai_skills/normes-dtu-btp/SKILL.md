## Réglementation transversale
- RE 2020 (Réglementation Environnementale) : applicable depuis 01/01/2022 pour le neuf
- RT 2012 : applicable pour les permis déposés avant RE 2020
- Réglementation sismique (Eurocode 8, zonage sismique)
- Réglementation incendie (IT 249, arrêtés ERP, Code du travail)
- Réglementation acoustique (NRA)
- Réglementation accessibilité PMR
- Diagnostic amiante avant travaux (DAT) obligatoire
- Diagnostic plomb avant travaux (CREP)

## Comment utiliser cette skill
Quand le CCTP cite une norme ou un DTU :
1. Identifier le DTU exact et son champ d'application
2. Vérifier que les prescriptions du CCTP sont cohérentes avec le DTU
3. Extraire comme exigence technique : "Respecter le NF DTU XX.X [intitulé]"
4. Si le CCTP impose des prescriptions plus contraignantes que le DTU, les extraire séparément
