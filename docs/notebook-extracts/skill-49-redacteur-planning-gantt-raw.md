## Q1 — Conventions Gantt + cohérence CCAP

**Gestion des intempéries et aléas :**
- Un planning trop optimiste est une **erreur fatale** : un délai irréaliste pénalise fortement la note.
- **Marges de sécurité** : le planning doit inclure et **montrer** des marges pour pallier les imprévus.
- **Jalons d'arrêt** : intégrer visuellement les périodes de congés et surtout les jours d'**intempéries hivernales** (facteur majeur pour ITE/Ravalement) ; montrer que le délai les absorbe.

**Cohérence absolue avec le CCAP (piège éliminatoire) :**
- Concordance stricte : le diagramme de Gantt doit s'aligner sur les **délais d'exécution imposés par le CCAP** / renseignés dans l'Acte d'Engagement.
- **Jurisprudence** : la Cour administrative d'appel a statué qu'un mémoire proposant un **délai d'exécution supérieur à celui imposé par le CCTP rend l'offre irrégulière** (rejet). De même, une incohérence interne (Acte d'Engagement 4 mois mais Gantt sur 5 mois) **disqualifie** l'offre.

**Conseil "excellent" (vs standard) :**
- **Annoter** le Gantt de commentaires montrant l'optimisation.
- Faire apparaître visuellement les **contraintes du RC** (milieu scolaire) : tâches bruyantes (perçage façades) planifiées sur mercredis / vacances scolaires / horaires hors présence des élèves.
