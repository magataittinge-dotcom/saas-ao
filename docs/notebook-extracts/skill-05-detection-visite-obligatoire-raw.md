## Q1 (N6) — Visite obligatoire : stipulation, qualification, sanction
- **Stipulation** : règles de visite (délais, modalités, attestation) dans le **RC** [1]. Le CCAP encadre l'exécution post-signature [2,3].
- **Obligatoire** : RC pose la visite comme **prescription imposée / exigence** [1] — formulations impératives + attestation à joindre.
- **Recommandée** : pas d'exigence stricte → offre non sanctionnable (une offre n'est irrégulière que si elle contrevient aux exigences des documents de consultation [1]).
- **Sanction non-respect** : offre **irrégulière** [4] → interdiction d'attribuer, élimination [1,5].
- **Jurisprudence** : *Tribunal Administratif de Rennes, ordonnance du 25 octobre 2010, Sarl PPR Ekdo Redon* [4] — validation du rejet automatique pour non-respect d'une visite imposée au RC.
