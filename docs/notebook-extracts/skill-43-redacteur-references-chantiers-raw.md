## Q1 — Format du tableau de références + photos + volumétrie

**Colonnes du tableau** (format Cariso/registry) : Année / Intitulé / Adresse / MOA / MOE / Lot / Montant HT. Détailler aussi nature des travaux, contraintes surmontées, respect des délais, contact MOA.

**Photos : OUI, absolument.** Preuves visuelles du savoir-faire. Idéal : **photos avant/après** ou détails techniques significatifs. Bonne pratique **SERI** : après le tableau récapitulatif, section « Réalisations illustrées » avec nombreuses photos (engins de levage, échafaudages, charpente nue puis couverture finalisée). 2 à 3 photos pertinentes **annotées** par référence retenue.

**Volumétrie : 3 à 5 références strictes.** Décalage observé : **Cariso liste 30+ références (2020-2023)**, **SERI une vingtaine (2015-2022)** → erreur "catalogue / plaquette commerciale" qui dilue le message. L'acheteur n'a pas le temps de tout lire. Optimal : extraire **uniquement les 3 à 5 chantiers les plus proches de l'AO** (ex. école → uniquement bâtiments scolaires / ERP), les détailler avec les colonnes ci-dessus, illustrer de 2-3 photos annotées.
