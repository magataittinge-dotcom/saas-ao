## Q2 — Méthodologie 4 phases (N4) — 1 retry

### Phase 1 — Préparation & études (NF DTU 59.1)
- T° ambiante **8-35 °C**, hygrométrie **< 70 %**.
- Humidité support en masse : **< 5 %** (béton/plâtre), **< 10 %** (béton cellulaire), **12 % ± 2 %** (bois).
- Choix finition : **A (Soigné) / B (Courant) / C (Élémentaire)**. Défaut = B.

### Phase 2 — Approvisionnement
- Étiquetage émissions **A+** (ISO 16000).
- COV : Directive 2004/42/CE.
- Écolabel Européen / NF Environnement.
- Classe de lessivabilité NF EN 13 300 (Classe 1 perd < 5 μm après 200 frottements ; Classe 3 : 20-70 μm).

### Phase 3 — Mise en œuvre (NF DTU 59.1)
- Préparation : ponçage, époussetage, rebouchage. **Finition A = ratissage complet** ; Finition B = ratissage localisé.
- **NF DTU 25.41** : plaques de plâtre, finition uniquement après **séchage 7 jours min** des joints en ambiance naturelle.
- Système : **Impression** (primaire régulateur) → **Couche intermédiaire** → **Couche finition**.
- Pièces d'eau : aspect **satiné** ; plafonds pièces sèches : **mat**.
- Points singuliers : calfeutrement / bandes de renfort sur jonctions matériaux (ex. plâtre/huisserie).

### Phase 4 — Contrôles & réception
- **Contrôle visuel à 2 m** (murs), centre de pièce (plafonds), sans lumière rasante.
- Tolérances planéité sous règle de 2 m :
  - **A** : ≤ **5 mm** (béton soigné ; correction).
  - **B** : **7 mm** (béton courant) ; **5 mm** (plâtre).
  - **C** : non spec. béton ordinaire ; **7 mm** béton cellulaire.
- Planéité locale plâtre/staff : **< 1 mm** sous réglet 0,20 m.

## Q3 — Pathologies & sinistralité (N4)

- **Revêtements mur intérieur + plafond (Code 75)** : Flop 10 sinistralité logement collectif.
- **Décollements / adhérence (plaques de plâtre)** : **34-40 %** des désordres revêtements/enduits sur supports maçonnés.
  - Causes : humidité > 5 %, préparation insuffisante (poussière, graisses, pas de primaire), surfaces non absorbantes (béton glacé). 
  - Prévention : reconnaissance fonds + propreté + humidité < 5 % ; **essai à la goutte d'eau** : support prêt si absorption en **60-240 secondes** ; impression régulatrice après séchage joints (NF DTU 59.1).
- **Taches / cloques / moisissures** : étanchéité (64 % cas) + condensation (1 % hausse). Prévention : locaux clos/couverts/chauffés/ventilés avant peinture ; **satiné en pièces d'eau** (résistant humidité, lessivable).
- **Écaillage / faïençage** : mouvements support, incompatibilité avec ancien revêtement. Prévention : essai quadrillage avant généralisation, respect délais séchage joints.
- **Spectres / fantômes** : reflet défauts subjectile sous lumière rasante. Prévention : niveau Finition A (ratissage complet), tolérance planéité 5 mm sous règle 2 m sur plaques, **contrôle visuel à 2 m sans lumière rasante**.

## Q5 — Contrôles & livrables (N4) — 1 retry

### Contrôles
- **Humidité support** : < 5 % béton/plâtre ; 12 % ± 2 % bois — humidimètre à pointes.
- **Reconnaissance fonds** : essai goutte d'eau (60-240 s), essai quadrillage ou arrachement sur supports anciens.
- **Délai séchage joints plâtre** : 7 jours min (NF DTU 25.41).
- **Contrôle visuel** : 2 m, angle normal, sans lumière rasante.

### Livrables
- **Fiches d'autocontrôle** (humidité, préparation, impression) — CCAG Art. 28.4.
- **DOE (CCAG Art. 40)** : plans récolement (localisation finitions), fiches CE/NF + étiquetage A+, notices entretien + classe lessivabilité (NF EN 13 300).
- **PAQ** (CCAG Art. 28.2) si marché le prévoit.
