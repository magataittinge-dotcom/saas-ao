## Q1 — Note d'innovation gagnante : utile vs gadget + cadre juridique variantes

**Innovation valorisée = immédiatement associée à un bénéfice chiffré et mesurable** pour l'acheteur. Justifier techniquement le procédé (plans, notes de calcul, fiches produits) ET présenter une **analyse de l'incidence financière** (économies générées ou surcoûts justifiés). Sinon = gadget.

**Cadre juridique — attention au hors-sujet (variantes) :**
- Si l'innovation **modifie les spécifications du CCTP** (autre isolant, autre mode de fixation) → c'est une **variante**.
- **Vérifier le RC** : en **MAPA**, variantes autorisées sauf indication contraire ; en **procédure formalisée**, interdites sauf autorisation explicite de l'acheteur.
- **Présenter séparément** : ne pas noyer une innovation majeure (modifiant le CCTP) dans la méthodologie de base ; produire un **mémoire technique distinct** pour la variante (parfois exigé sous peine de rejet).
- **L'offre de base reste obligatoire** : le RC peut subordonner la variante à la remise d'une offre de base strictement conforme ; ne répondre qu'avec la solution innovante → rejet.
